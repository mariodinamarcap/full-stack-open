# 0.5: Aplicación de una sola página

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser,server: El usuario entra a la página

    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/spa
    activate server
    server-->>browser: Status 200, HTML
    deactivate server

    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/main.css
    activate server
    server-->>browser: Status 200, CSS
    deactivate server

    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/spa.js
    activate server
    server-->>browser: Status 200, javascript
    deactivate server

    Note right of browser: ahí se ejecuta el código JavaScript, que pide el dato JSON

    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/data.json
    activate server
    server-->>browser: Status 200, JSON con la lista completa de notas
    deactivate server

    Note right of browser: se dibujan en la página todas las notas que vienen
```
